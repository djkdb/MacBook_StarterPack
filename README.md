# 맥북 스타터팩 (MacBook Starter Pack)

맥북을 처음 산 사람을 위한 **인터랙티브 퀘스트형 가이드**입니다.

설명서를 읽는 방식이 아닙니다. 브라우저가 실제 키 입력과 트랙패드 제스처를 감지해서,
**직접 눌러야 다음 단계로 넘어갑니다.**

- 9개 챕터 · 66개 퀘스트 · 총 1180 XP
- 레벨과 칭호(맥린이 → 맥북 마스터), 챕터별 배지
- 진행 상황은 브라우저에 자동 저장 (`localStorage`)
- 인쇄 가능한 단축키 치트시트 내장
- 의존성 없음 — HTML/CSS/JS 파일 몇 개가 전부입니다

## 실행하기

가장 간단한 방법은 그냥 파일을 여는 것입니다.

```bash
open index.html
```

로컬 서버로 띄우고 싶다면:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

다른 사람에게 링크로 주고 싶다면 GitHub Pages를 켜면 됩니다.
저장소 **Settings → Pages → Source: Deploy from a branch** 에서 브랜치와 `/ (root)` 를
고르면 별도 빌드 없이 바로 배포됩니다. 정적 파일이라 설정할 게 없습니다.

> 판정 기능은 **macOS의 브라우저에서 열어야** 정상 동작합니다.
> 맥이 아닌 기기에서 열면 시작 화면에 안내가 표시되고, 내용은 그대로 볼 수 있습니다.

## 파일 구조

```
index.html    화면 뼈대
styles.css    스타일 (다크 테마, 반응형, 치트시트 인쇄용 스타일 포함)
quests.js     모든 콘텐츠 — 챕터·퀘스트·랭크·배지·치트시트
engine.js     판정 엔진 — 키/제스처/클립보드 감지
app.js        진행 상태, 화면 전환, 저장
```

콘텐츠와 판정 로직이 분리되어 있어서, **퀘스트를 추가하려면 `quests.js`만 건드리면 됩니다.**

## 판정 방식

`quests.js`의 각 퀘스트는 `check.t` 로 판정 방식을 고릅니다.

| `check.t` | 판정 내용 |
|-----------|-----------|
| `mod` | 수식어 키 하나를 누름 (`keydown`) |
| `allmods` | ⌘⌥⌃⇧ 를 동시에 누름 |
| `combo` | 단축키 조합. `spec:'cmd+shift+z'` 형식 |
| `editor` | 연습용 텍스트 상자의 편집 결과·커서 위치 비교 |
| `scroll` | 지정한 축의 휠 델타 누적 (두 손가락 스크롤/스와이프) |
| `pinch` | `ctrlKey`가 붙은 `wheel`(Chrome·Firefox) 또는 `gesturechange`(Safari) |
| `contextmenu` | 두 손가락 클릭 = 보조 클릭 |
| `pasteImage` | 붙여넣은 클립보드에 이미지가 들어 있는지 확인 |
| `emoji` | 입력값에 이모지가 포함되었는지 확인 |
| `answer` | 정답 문자열 입력 (공백·쉼표 무시) |
| `blur` | 브라우저가 포커스를 잃었다 돌아옴 |
| `quiz` / `manual` | 객관식 / 직접 해보고 체크 |

키 조합은 `e.key`가 아니라 **`e.code`로 판정**합니다. macOS에서 ⌥를 누른 채 글자를 치면
`e.key`가 특수문자(`˙`, `ø` 등)로 바뀌고, 한글 입력 상태에서도 값이 달라지기 때문입니다.

### 판정이 완벽하지 않은 부분 (알고 쓰세요)

브라우저가 볼 수 없는 것들이 있습니다. 해당 퀘스트는 정직하게 다른 방식으로 처리했습니다.

- **⌘Space(Spotlight), ⌃↑(미션 컨트롤), 네 손가락 오므리기(Launchpad)** 등은 macOS가
  가로채서 웹페이지까지 키 이벤트가 오지 않습니다. → `blur` 로 "화면을 다녀왔다"는 사실만
  확인합니다. 어떤 단축키를 썼는지까지는 구분하지 못합니다.
- **⌘⇧3 / ⌘⇧4 스크린샷**은 키 이벤트도, 포커스 변화도 발생하지 않습니다. → 직접 확인(`manual`)
  입니다. 다만 보스 퀘스트인 **⌃⌘⇧4(클립보드로 캡처)** 는 붙여넣기로 이미지를 실제로 검증합니다.
- **⌘`(같은 앱 창 전환)** 도 macOS가 직접 처리하므로 `manual` 입니다.
- 시스템 설정을 바꾸는 퀘스트(9챕터 등)는 당연히 감지할 수 없어 체크박스 방식입니다.

`editor` 판정에는 `via` 옵션이 있어서, 마우스로 커서를 옮겨 우연히 통과하는 걸 막습니다.
지정한 단축키를 실제로 누른 경우에만 정답으로 인정합니다.

### 브라우저 기본 동작 차단

학습을 방해하는 기본 동작은 막아둡니다. 입력칸 **밖**에서 누른 ⌘ 조합은 `preventDefault`
처리되어, ⌘←로 뒤로 가버리거나 ⌘S로 저장 대화상자가 뜨는 일이 없습니다.
다만 ⌘R(새로고침), ⌘T, ⌘N, ⌘W, ⌘Q 는 탈출구로 남겨두었습니다.

## 퀘스트 추가하기

`quests.js`의 원하는 챕터 `quests` 배열에 객체를 하나 넣으면 끝입니다.

```js
{
  id: 'k-newtab',                 // 저장에 쓰이므로 고유해야 합니다
  title: '새 탭 열기',
  sub: '⌘T',                       // 짧으면 사이드바와 치트시트에 자동으로 실립니다
  xp: 10,
  how: ['⌘ 를 누른 채 T 를 누르세요.'],
  tip: '클리어한 뒤에 보여줄 한 줄 지식',
  check: { t: 'combo', spec: 'cmd+t' }
}
```

XP를 늘렸다면 `RANKS`의 마지막 기준값이 총 XP를 넘지 않는지 확인하세요.
넘으면 최고 랭크에 도달할 수 없습니다.

```bash
node -e "
const src=require('fs').readFileSync('quests.js','utf8');
const {CHAPTERS,RANKS}=new Function(src+';return {CHAPTERS,RANKS};')();
const total=CHAPTERS.flatMap(c=>c.quests).reduce((s,q)=>s+q.xp,0);
console.log('총 XP', total, '/ 최고 랭크', RANKS.at(-1).xp, total>=RANKS.at(-1).xp?'OK':'도달 불가!');
"
```

## 진행 상황 초기화

상단 오른쪽 **↺ 초기화** 버튼을 누르면 됩니다.
저장 위치는 `localStorage`의 `macbook-starterpack.v1` 키 하나입니다.
