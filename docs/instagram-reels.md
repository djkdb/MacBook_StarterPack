# 인스타그램 릴스 운영 브리프

맥북 스타터팩을 릴스로 알리려는 사람에게 넘기는 문서입니다.
이 프로젝트를 처음 보는 사람도 이 문서만 읽고 바로 촬영에 들어갈 수 있게 썼습니다.

**목표는 조회수가 아니라 "맥북 앞에 앉아서 링크를 여는 사람"의 수입니다.**
릴스는 잘 터졌는데 아무도 링크를 안 열면 실패한 편입니다.

---

## 1. 먼저 알아야 할 세 가지

### ① 유입은 사실상 100% 아이폰입니다

릴스를 보는 사람은 휴대폰을 들고 있습니다. 프로필 링크를 누르면 인스타 인앱
브라우저가 열립니다. **그런데 이 가이드는 맥에서 해야 합니다.** ⌘ 키를 누르고
트랙패드를 쓸어야 다음으로 넘어가는 구조라서요.

### ② 그래서 랜딩이 휴대폰 방문자를 따로 받습니다

맥이 아닌 기기로 들어오면 "맥이 아니네요"가 아니라 **맛보기 3문제**가 먼저 뜹니다.
손가락으로 풀 수 있고, 다 풀면 주소 복사 버튼이 나옵니다.

맛보기 3문제는 이것입니다 (`quests.js` 의 `TEASER`):

1. 맥에서 복사는 Ctrl+C가 아니다 → **⌘C**
2. Finder에서 파일 고르고 엔터 → 열리는 게 아니라 **이름 바꾸기**
3. ⌘W로 창을 닫아도 **앱은 살아 있다** (끄려면 ⌘Q)

> **릴스와 랜딩은 같은 이야기여야 합니다.**
> 릴스에서 던진 훅이 링크를 열자마자 다시 나오면 "어 이거네" 하고 이어집니다.
> 훅을 새로 지어내지 말고, 되도록 위 3개 또는 아래 4번 표에서 고르세요.

### ③ 진짜 전환은 "맥에서 다시 열기"입니다

휴대폰에서 링크를 여는 건 절반입니다. 나머지 절반은 그 링크가 맥으로 건너가는 것.
랜딩의 복사 버튼이 그 다리인데, **아이폰에서 복사하면 같은 계정 맥에 그대로
붙여넣어진다(유니버설 클립보드)**는 안내가 붙어 있습니다.
이 기능 자체가 이 가이드 9챕터 내용이라, 릴스 소재로도 좋습니다.

---

## 2. 릴스 한 편의 구조

15~25초. 한 편에 **한 가지만** 다룹니다.

| 구간 | 시간 | 할 일 |
|---|---|---|
| 훅 | 0 ~ 2초 | 질문 또는 단언을 자막으로 크게. 말보다 글자가 먼저 |
| 시연 | 2 ~ 8초 | 맥 화면 녹화. 손이 아니라 **화면**이 주인공 |
| 반전 | 8 ~ 15초 | "그래서 이게 왜 중요한지" 한 문장 |
| CTA | 마지막 2~3초 | "프로필 링크에서 직접 눌러볼 수 있어요" |

**첫 2초에 실패하면 나머지는 없습니다.** 인사·자기소개·브랜드 인트로는 넣지 마세요.
바로 "맥에서 창 닫으면 앱이 꺼진 줄 알았죠?" 로 시작합니다.

---

## 3. 훅 재료 — 실제 콘텐츠에서 뽑은 것

전부 가이드 안에 있는 내용입니다. 오른쪽 퀘스트 ID로 원문을 찾을 수 있습니다
(`quests.js` 에서 검색).

### A급 — 반전이 강해서 먼저 쓸 것

| 훅 자막 | 화면에 보여줄 것 | 퀘스트 |
|---|---|---|
| "맥에서 ⌘W로 닫아도 앱은 안 꺼집니다" | Dock에 점 켜진 앱이 20개 쌓인 화면 → ⌘Q로 정리 | `w-quiz` (6장) |
| "맥엔 잘라내기가 없습니다" | ⌘X 눌러도 안 되는 장면 → ⌘C 후 **⌥⌘V** 로 이동 | `f-move` (8장) |
| "파일 고르고 엔터 누르면 안 열려요" | 엔터 → 이름 바꾸기가 켜지는 장면 | `f-quiz` (8장) |
| "사진 속 글자를 그냥 복사할 수 있습니다" | 사진 위 글자 드래그 → 붙여넣기 | `f-livetext` (8장) |
| "PDF 합치려고 사이트 찾지 마세요" | 미리보기에서 축소판 드래그로 합치기 | `f-preview` (8장) |
| "한/영 전환은 캡스락입니다" | 캡스락 눌러 메뉴 막대 A ↔ 가 바뀌는 장면 | `t-hangul` (3장) |

### B급 — 실용적이라 저장·공유가 잘 나옴

| 훅 자막 | 화면에 보여줄 것 | 퀘스트 |
|---|---|---|
| "스페이스바 한 번이면 다 열립니다" | 사진·PDF·동영상·zip 연달아 훑어보기 | `f-quicklook` (8장) |
| "파일 100개 이름 한 번에 바꾸기" | 다중 선택 → 이름 변경 | `f-rename` (8장) |
| "이 설정 하나로 창 옮기기가 편해집니다" | 세 손가락 드래그 켜고 창 끌기 | `tp-drag3` (4장) |
| "계산기 열지 마세요" | ⌘Space 에 환율·단위 넣기 | `sp-calc` (5장) |
| "복사한 걸 다시 꺼낼 수 있습니다" | ⌘Space → ⌘4 클립보드 기록 | `sp-modes` (5장) |
| "아이폰을 맥 화면에서 그대로 씁니다" | iPhone 미러링 | `eco-mirror` (9장) |

### C급 — 오해를 바로잡는 것 (댓글이 붙음)

| 훅 자막 | 요지 | 퀘스트 |
|---|---|---|
| "80%마다 충전기 뽑는 거, 안 해도 됩니다" | 배터리 충전 최적화가 알아서 함 | `s-battery` (11장) |
| "'시스템 데이터' 100GB의 정체" | 캐시·스냅샷·기기 백업 | `st-systemdata` (10장) |
| "앱이 '확인되지 않은 개발자'라고 뜰 때" | 바이러스가 아니라 애플 미보증 | `f-install` (8장) |

## 4. 촬영과 편집

- **화면 녹화는 ⇧⌘5.** 이 가이드 7챕터에서 가르치는 기능이라, 만드는 과정 자체가 소재가 됩니다.
- **9:16 세로.** 맥 화면은 가로라서 그대로 넣으면 작아집니다. 창 하나만 크게 띄우고
  필요한 영역만 잘라서 확대하세요. 전체 데스크탑을 다 보여주지 마세요.
- **커서를 크게.** 시스템 설정 > 손쉬운 사용 > 디스플레이 > 포인터 크기.
  안 키우면 휴대폰 화면에서 뭘 누르는지 안 보입니다.
- **소리 없이 봐도 이해되게.** 릴스는 대부분 무음으로 재생됩니다. 자막이 본체입니다.
- **키 입력을 화면에 띄우세요.** ⌘ ⌥ ⇧ 같은 기호가 눌릴 때 보여야 따라할 수 있습니다.
- **한 편에 한 가지.** 욕심내서 세 개 넣으면 아무것도 안 남습니다.

## 5. 캡션과 CTA

### 캡션 틀

```
[훅을 한 번 더, 한 줄로]

[한 문장 설명]

직접 눌러보는 건 프로필 링크에 있어요.
읽는 가이드가 아니라 진짜 눌러야 넘어가는 퀘스트입니다.
맥북 앞에서 열어주세요 👀

#맥북 #맥북입문 #맥북꿀팁 #애플 #macos #맥북단축키
#맥북초보 #newmacbook #직장인꿀팁 #생산성
```

### CTA에서 반드시 말할 것

- **"맥북 앞에서 열어주세요"** — 이 한마디가 없으면 휴대폰에서 열어보고 끝냅니다.
- 링크에서 뭘 하게 되는지 한 마디 (예: "3문제 맞혀보고 시작해요")

### 고정 댓글

첫 댓글에 링크를 한 번 더 넣고, "폰에서 복사해두면 맥에서 ⌘V로 바로 붙여넣어져요"
를 덧붙이세요. 그 자체가 가이드 내용이라 재미로 읽힙니다.

## 6. 시리즈 운영

- **주 2~3편**, 한 편에 한 주제.
- 순서는 위 표의 **A급 → B급 → C급**. 초반에 가장 센 것을 씁니다.
- A급을 다 쓰면 **파트 단위로 묶어** "맥북 산 첫날 할 것 5가지" 같은 모음 편을 냅니다.
- 반응이 좋은 편은 **같은 주제를 다른 훅으로** 다시 만드세요. 새 주제보다 잘 나옵니다.
- 스토리에는 맛보기 3문제를 그대로 **퀴즈 스티커**로 올리면 반응률이 높습니다.

---

## 7. 하지 말 것

- **"맥북 100% 활용법" 같은 뭉뚱그린 제목.** 구체적인 한 가지가 이깁니다.
- **초보를 깎아내리는 톤.** "이것도 몰랐어?" 는 이 프로젝트의 톤이 아닙니다.
  가이드 본문 자체가 "괜찮습니다, 여기 온 사람 대부분이 이렇게 시작해요" 톤입니다.
- **없는 기능 지어내기.** 전부 macOS 26 Tahoe 기준으로 검증된 내용만 있습니다.
  확실하지 않으면 `quests.js` 의 해당 퀘스트 원문을 확인하세요.
- **애플 공식처럼 보이게 만들기.** 비공식 학습 자료입니다. 로고나 공식 서체를
  가져다 쓰지 마세요.
- **음악만 깔고 자막 없이 내보내기.** 무음 시청에서 아무것도 전달되지 않습니다.

## 8. 성과 판단

조회수보다 아래 순서로 봅니다.

1. **링크 클릭 수** — 릴스가 실제로 행동을 만들었는지
2. **저장 수** — "나중에 맥에서 해봐야지"의 신호. 이 콘텐츠에서 가장 중요한 지표
3. **댓글** — "이거 몰랐어요" 가 달리면 훅이 맞은 것
4. 조회수 / 공유

**저장은 많은데 클릭이 적으면** CTA가 약한 겁니다 — "맥북 앞에서 열어주세요"를 더 크게.
**클릭은 많은데 반응이 없으면** 훅과 랜딩의 첫 화면이 어긋난 겁니다 — 맛보기 3문제
중 하나를 훅으로 바꾸세요.
